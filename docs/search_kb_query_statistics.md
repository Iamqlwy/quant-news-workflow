## 二、参数分布统计

### 2.1 limit 分布

`limit` 控制每次搜索返回的条数（最大值 20）。

| limit | 次数 | 占比 |
|-------|------|------|
| 10（默认值） | 28,532 | 88.0% |
| 5 | 3,177 | 9.8% |
| 8 | 252 | 0.8% |
| 20（最大值） | 153 | 0.5% |
| 未传 | 136 | 0.4% |
| 15 | 97 | 0.3% |
| 3 | 40 | 0.1% |
| 6 | 21 | 0.1% |
| 1 | 7 | <0.1% |

88% 的调用使用默认值 10，9.8% 使用 5，其他分布很零星。说明系统绝大部分时候接受默认返回条数。

### 2.2 target_tables 分布

`target_tables` 限定搜索的知识库表范围：`raw_information`（原始资讯）、`analyses`（分析报告）、`feedbacks`（复盘反馈）、`nodes`（节点状态）。不填则搜索全部表。

| target_tables | 次数 | 占比 |
|---------------|------|------|
| 未填（搜全部） | 23,831 | 73.5% |
| nodes | 2,393 | 7.4% |
| analyses,feedbacks | 1,254 | 3.9% |
| analyses | 1,007 | 3.1% |
| analyses,raw_information | 933 | 2.9% |
| feedbacks | 898 | 2.8% |
| raw_information | 701 | 2.2% |
| analyses,feedbacks,raw_information | 442 | 1.4% |
| analyses,nodes | 391 | 1.2% |
| analyses,nodes,raw_information | 245 | 0.8% |
| feedbacks,raw_information | 160 | 0.5% |
| 其他组合 | 160 | 0.5% |

关键观察：
- 73.5% 不限定范围，搜全部表——大多数场景需要全量信息。
- 限定单表时，**nodes** 最热门（7.4%），说明节点状态检索是一个高频专项需求。
- **analyses+feedbacks**（3.9%）是第二热门的限定组合，主要用于复盘+分析联合检索。

## 七、关键发现

1. **超长尾分布**：93.4% 的查询仅出现 1 次，说明系统搜索行为非常发散，用户/Agent 研究覆盖范围极广。
2. **中芯国际是绝对核心**：出现 897 次，远超第二名比亚迪（214 次），围绕其基本面、制裁、节点逻辑、复盘等维度被反复检索。
3. **复盘文化突出**："复盘"出现 741 次，"教训" 464 次，"证伪" 617 次，"判断错误" 224 次——说明系统有较强的"事后总结+纠错"行为模式。
4. **节点驱动**："节点"出现 1,367 次，"WorldNode" 1,112 次，"投资逻辑" 904 次——大量的搜索是为了理解/更新节点状态和投资逻辑。
5. **时间锚点明显**："2026"（4,224）、"2025"（1,580）、"2026年3月"（677）、"2026年5月"（186）——搜索强依赖时间维度，关注特定时期的业绩/事件。
6. **风险意识强**："风险"出现 1,620 次，"亏损" 647 次，"不及预期" 338 次，"泡沫" 271 次——系统对负面信号高度敏感。
7. **半导体主线**："半导体" 477 次、"芯片" 367 次、"存储芯片" 448 次、"国产替代" 328 次——半导体产业链是最受关注的行业方向。
